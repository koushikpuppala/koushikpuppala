## 💫 About Me

Hi there, I'm Koushik Puppala, a Full Stack Developer at **[Earnest Data Analytics](https://earnestdata-analytics.in)** in Noida, India. I have 3+ years of experience building end-to-end web features with React, Next.js, Node.js and PostgreSQL, with a focus on frontend performance, clean architecture and dependable backend integration.

Alongside my work, I mentor and oversee the website team at the **[Indian Institute of Information Technology Raichur](https://iiitr.ac.in)**, where I earned my B.Tech in Computer Science and Engineering, led the website team as a student and served as the Google Developer Student Clubs lead. Before Earnest, I built authentication and payment flows at **[Upraised®](https://upraised.in)** and worked on frontend tooling at MapleMonk.

- 🔭 Currently building **_SEO-friendly Next.js frontends, Node.js APIs and AWS infrastructure_** for production workloads.

- 🧩 This repository is my **_[portfolio](https://koushikpuppala.com)_**, open source since December 2020: a monorepo with a Next.js 16 site, a Next.js admin studio and a NestJS API on PostgreSQL, Redis and AWS.

- 👯 Mentoring the **_[IIIT Raichur](https://iiitr.ac.in)_** website team.

- 💬 Ask me about **_Next.js, React, TypeScript, Node.js, NestJS, PostgreSQL and AWS_**.

- 📫 Reach me through the contact form on my **_[website](https://koushikpuppala.com/contact)_** or on **_[LinkedIn](https://linkedin.com/in/koushikpuppala)_**.
